# Software engineering

Software engineering is the discipline of building software that works, lasts and can be changed safely by teams: requirements, design, testing, version control, and managing complexity over years.

## Key works
- beginner · *The Pragmatic Programmer* · David Thomas and Andrew Hunt · 1999 (20th anniversary edition 2019) · paid | Practical habits of good programmers.
- beginner · *The Mythical Man-Month* · Frederick P. Brooks Jr. · 1975 (anniversary edition 1995) · paid | Why adding people to a late project makes it later.
- intermediate · *Software Engineering at Google* · Titus Winters, Tom Manshreck and Hyrum Wright · 2020 · free | How a large company builds software; free to read online.
- intermediate · Missing Semester of Your CS Education · MIT · 2020 · free | Free lectures on version control, the command line and tools.
- advanced · *Designing Data-Intensive Applications* · Martin Kleppmann · 2017 · paid | How reliable, scalable systems are built.

## Quick check
**Multiple choice.** What does Brooks's law say?
- Adding people to a late software project makes it later ✓
- Software is always on time
- More code is always better

**Multiple choice.** What is version control for?
- Tracking changes to code so teams can work together and undo mistakes ✓
- Controlling screen brightness
- Counting users

**Multiple choice.** Why write automated tests?
- To catch mistakes when code changes ✓
- To slow the computer
- To replace users
