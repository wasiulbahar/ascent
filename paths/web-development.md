# Web Development

How websites and web apps are built: how the web works, HTML and CSS, JavaScript, accessible and responsive design, back ends and databases, frameworks and deployment, security and performance. About 250 to 300 hours over ten to twelve months.

**Access and balance.** Every title is labelled **Free**, **Free + paid** or **Paid**. Everything here can be learned free: MDN, freeCodeCamp, The Odin Project and free hosting. You need only a computer and a browser. The path teaches web standards first, so your skills last when frameworks change, and treats accessibility as essential, not optional.

# About web development

Web development is building websites and web applications: the pages you see (front end), the servers and databases behind them (back end), and the tools to test and deploy them. The web is the world's largest software platform.

This path begins with how the web works and your first page, teaches HTML and CSS, JavaScript, accessibility and responsive design, back ends and databases, and ends with frameworks, deployment, security and performance.

**Trivia**
- Tim Berners-Lee proposed the World Wide Web at CERN in 1989; the first website went live in 1991.
- JavaScript was created in about ten days in 1995 by Brendan Eich.
- Over 95% of the world's top million home pages have detectable accessibility failures, according to WebAIM's annual survey.
- Over half of web traffic now comes from mobile phones.

### Timeline
- **1989 · Tim Berners-Lee** proposes the World Wide Web.
- **1991 · The first website** goes live at CERN.
- **1995 · JavaScript** is created.
- **1996 · CSS** is first published as a standard.
- **1999 · WCAG 1.0** the first web accessibility guidelines.
- **2006 · jQuery** simplifies JavaScript.
- **2008 · Chrome** launches with a fast JavaScript engine.
- **2010 · Responsive web design** is named by Ethan Marcotte.
- **2013 · React** is released.
- **2014 · HTML5** becomes a W3C recommendation.

# What you will be able to do

At the end of this path you will build for the web the way a strong first year of a web development course expects. You will be able to:

- **Explain how the web works:** browsers, servers, HTTP and DNS.
- **Build pages with HTML and CSS:** semantic structure, layout and responsive design.
- **Program with JavaScript:** the DOM, events, fetching data and modules.
- **Build accessible sites:** following WCAG, for keyboard and screen-reader users.
- **Build and deploy full apps:** back ends, databases, frameworks, security and performance.
- **For the Mastery certificate:** have written the Scholar challenges and passed the final mastery check.

These goals are a draft standard. Web developers and educators from more than one country will confirm them before the path is published.

**How stages work.** Each work ends with a short quiz. Score 70% or more across a stage's quizzes to pass it. If you fall short, you can retake the quizzes, or continue anyway: the stage then stays marked **Not finished** until you come back and pass it.

# Final mastery check

Finishing all six stages makes you a capable web developer. To earn the **Ascent Mastery: Web Development** certificate, you also complete:

1. **The grand quiz.** 40 game-style questions across all six stages. Pass mark 80%, with unlimited retakes.
2. **Build task.** Build an accessible, responsive page from an unseen design.
3. **Project.** Build and deploy a full app with a back end.
4. **Capstone essay.** 2,500 words on one of the Stage 6 questions. Strong essays are read by an expert reviewer.
5. **Explain it.** Answer three unseen questions as if to a curious friend. For example: “What happens when I type a web address?”

The certificate needs every stage passed.
