# Programming

Learn to code from scratch: thinking like a programmer, Python basics, data structures and algorithms, writing clean and tested code, working with data, the web and version control, and building real projects. About 250 to 300 hours over ten to twelve months.

**Access and balance.** Every title is labelled **Free**, **Free + paid** or **Paid**. Almost everything needed to learn programming is free: courses, books, tools and practice sites. You need only a computer and an internet connection; a phone with a browser editor can get you started. The path uses Python first, then shows how ideas carry over to other languages.

# About programming

Programming is writing precise instructions that computers follow. It powers apps, websites, science, games and businesses, and it is a powerful way of thinking: breaking problems into steps, testing ideas and fixing mistakes.

This path begins with gentle introductions and your first programs, teaches Python fundamentals, explains data structures and algorithms, covers writing clean and tested code, explores data, the web and version control, and ends with building and sharing real projects.

**Trivia**
- Ada Lovelace wrote what is often called the first computer program, in 1843, for a machine that was never built.
- Grace Hopper's team popularised the term “debugging” after finding a moth in a computer relay in 1947.
- Python, first released in 1991, is named after the comedy group Monty Python, not the snake.
- Most programmers spend more time reading and fixing code than writing new code.

### Timeline
- **1843 · Ada Lovelace** writes an algorithm for the Analytical Engine.
- **1936 · Alan Turing** defines what can be computed.
- **1949 · The first stored programs** run on EDSAC and the Manchester Baby.
- **1957 · FORTRAN** the first widely used high-level language.
- **1972 · The C language** is created at Bell Labs.
- **1991 · Python** is released by Guido van Rossum.
- **1995 · JavaScript** brings programming to web pages.
- **2005 · Git** transforms how programmers share code.
- **2008 · GitHub** launches.
- **2020s · AI coding assistants** change how code is written.

# What you will be able to do

At the end of this path you will program the way a strong first year of a university programming course expects. You will be able to:

- **Write programs in Python:** variables, conditions, loops, functions and files.
- **Use data structures and algorithms:** lists, dictionaries, searching, sorting and complexity.
- **Write clean, tested code:** readable names, small functions, tests and debugging.
- **Work like a developer:** the command line, Git, libraries and documentation.
- **Build and share a project:** from idea to working program, with AI tools used wisely.
- **For the Mastery certificate:** have written the Scholar challenges and passed the final mastery check.

These goals are a draft standard. Programmers and computing teachers from more than one country will confirm them before the path is published.

**How stages work.** Each work ends with a short quiz. Score 70% or more across a stage's quizzes to pass it. If you fall short, you can retake the quizzes, or continue anyway: the stage then stays marked **Not finished** until you come back and pass it.

# Final mastery check

Finishing all six stages makes you a capable programmer. To earn the **Ascent Mastery: Programming** certificate, you also complete:

1. **The grand quiz.** 40 game-style questions across all six stages. Pass mark 80%, with unlimited retakes.
2. **Coding task.** Solve unseen programming problems in Python.
3. **Project.** Build and share a working project with tests and a README.
4. **Capstone essay.** 2,500 words on one of the Stage 6 questions. Strong essays are read by an expert reviewer.
5. **Explain it.** Answer three unseen questions as if to a curious friend. For example: “What actually happens when I run a program?”

The certificate needs every stage passed.
